# Taza Niyet

**«Чистое намерение»** — мобильное приложение для волонтёров. Каждый час работы подтверждает
координатор, за него начисляются баллы, растут уровень и навыки, а итог можно получить
сертификатом с QR-кодом для проверки.

React Native + Expo SDK 58 (iOS, Android, веб), бэкенд — Supabase (Postgres с RLS, Auth, Storage,
Realtime, pg_cron). Языки интерфейса: қазақша, русский, English.

## Запуск за 5 минут

Нужны **Node.js 20+** и запущенный **Docker Desktop**.

```bash
npm install
```

```bash
npm run db:start
```

Поднимает локальный Supabase и создаёт базу с тестовыми данными. Первый запуск скачивает
образы (около 4 ГБ) — дальше старт занимает секунды.

```bash
npm run setup:env
```

Записывает в `.env` адрес и публичный ключ локального Supabase (секретные ключи в клиент
не попадают).

```bash
npm run web
```

Откроется http://localhost:8081. Для телефона — `npm start` и QR-код в Expo Go
(или `a` — эмулятор Android, `i` — симулятор iOS).

### Вход

Вход — по одноразовому коду на email. Письма локального Supabase приходят в почтовый ящик
**http://127.0.0.1:54324** — код из письма вводится в приложении.

| Роль            | Email                                  | Что посмотреть                                   |
| --------------- | -------------------------------------- | ------------------------------------------------ |
| Админ           | `admin@taza.test`                      | Организация → админ-панель: споры, отчёты, аудит |
| Координатор     | `coord1@taza.test`, `coord2@taza.test` | Квест → смена: QR для отметок, подтверждение     |
| Волонтёр        | `vol1@taza.test` … `vol10@taza.test`   | Лента квестов, «Моя выгода», сертификаты         |
| Без организации | `newbie@taza.test`                     | Вступление по приглашению                        |

Приглашение в организацию для разработки: http://localhost:8081/join/tazaqala-join-01

## Что умеет приложение

- **Квесты:** лента с фильтрами и картой, запись и лист ожидания, отмена не позже чем за N часов.
- **Учёт часов:** динамический QR (меняется каждые 30 секунд), отметка с проверкой геолокации,
  ручная отметка координатором, автозакрытие смены, работа без сети с последующей
  синхронизацией без дублей. Часы считает сервер, округление — до 15 минут в пользу волонтёра.
- **Подтверждение и споры:** координатор подтверждает часы и ставит оценки; любая правка —
  с причиной и в журнале аудита; волонтёр может оспорить часы, решает админ.
- **Баллы и «Моя выгода»:** формула по сложности, длительности и оценкам, уровни, навыки,
  достижения, рейтинг организации.
- **Сертификаты:** PDF с QR-кодом; по QR открывается публичная страница проверки без входа.
- **Админ-панель:** задачи «сверху», журнал аудита, отчёты по часам (CSV для Excel и PDF),
  отзыв сертификатов.
- **Уведомления:** пуши (новые квесты, запись, напоминания за 24 ч и за 2 ч, подтверждённые часы,
  достижения, ответы по спорам), лента уведомлений в реальном времени, настройки по группам.
- **Удобство на улице:** крупные кнопки (≥ 56 dp) для работы в перчатках, плашка «Нет сети»,
  светлая и тёмная тема, поддержка экранных чтецов и увеличенного шрифта; анимации отключаются
  системной настройкой «Уменьшить движение».

## Проверки

```bash
npm run check     # TypeScript + ESLint + Jest
npm run db:test   # pgTAP: RLS, изоляция организаций, учёт часов, баллы, пуши
```

Остальные команды:

```bash
npm run db:reset  # пересоздать БД из миграций и seed
npm run db:types  # обновить типы БД после изменения схемы
npm run db:stop   # остановить локальный Supabase
```

Панель базы данных (Studio): http://127.0.0.1:54323.

## Устройство проекта

```
src/app/              маршруты Expo Router (экраны и layout)
src/features/<фича>/  логика: api.ts, queries.ts, schemas.ts (zod), components/, __tests__/
src/components/ui/    общие компоненты: Button, Card, EmptyState, QueryState (скелетоны)…
src/i18n/locales/     переводы; ru — эталон, kk и en сверяются тестом
supabase/migrations/  схема, RLS и бизнес-правила (security definer функции)
supabase/tests/       pgTAP-тесты политик и расчётов
```

Безопасность держит сервер: RLS на каждой таблице; запись в учёт часов, баллы и сертификаты —
только через проверяющие функции; журналы аудита и баллов только дополняются. Правила проекта —
в [CLAUDE.md](CLAUDE.md), принятые решения и их причины — в [DECISIONS.md](DECISIONS.md).

## Публичная проверка сертификата

QR на PDF-сертификате ведёт на `<EXPO_PUBLIC_WEB_URL>/verify/<id>`. Страница открывается
без входа и показывает только то, что напечатано на сертификате. Для разработки адрес —
`http://localhost:8081`; перед выпуском укажите в `.env` боевой домен веб-версии.

## Push-уведомления на телефоне

Пуши приходят только в сборке приложения (development build или EAS) — не в Expo Go
и не в браузере; там уведомления видны во вкладке «Уведомления». Чтобы включить пуши:

```bash
npx eas-cli@latest init
```

Команда добавит `projectId` в конфигурацию. Для Android загрузите ключ FCM:

```bash
npx eas-cli@latest credentials
```

Отправкой занимается сама база (pg_cron + pg_net → Expo Push API), отдельный сервер не нужен.

## Если что-то не работает

- **`npm run db:start` падает** — запущен ли Docker Desktop? Порты 54321–54324 должны быть свободны.
- **На экране входа «Сервер не настроен»** — не выполнен `npm run setup:env`, или dev-сервер
  запущен раньше: перезапустите `npm run web`.
- **Код не приходит** — письма не уходят на настоящую почту, смотрите http://127.0.0.1:54324.
- **Windows блокирует `supabase.exe`** («Application Control policy») — разрешите файл
  `node_modules/@supabase/cli-windows-x64/bin/supabase.exe` в настройках безопасности Windows
  (Smart App Control).
